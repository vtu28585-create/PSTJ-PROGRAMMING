Task 4: Find Maximum Element


public class MaximumElement {
    public static void main(String[] args) {

        int[] arr = {15, 45, 22, 78, 10};

        int max = arr[0];

        for (int i = 1; i < arr.length; i++) {
            if (arr[i] > max)
                max = arr[i];
        }

        System.out.println("Maximum = " + max);
    }
}


OUTPUT:

Maximum = 78
